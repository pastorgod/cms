el-form要保存内容，
需要绑定一个vue对象
:model="form"

```ts
const searchFrom = ref({
    name: '',
})
```

想操作el-form，比如重置所有控件

```ts
const formRef = ref<InstanceType<typeof ElForm>()

function handleReset(){
    formRef.value?.resetFields() 
}
```

ref="refForm"

⚠️注意：
要使用formRef.value.resetFields() 或者类似操作，需要给el-form 每个组件绑定 prop="name"
这个name是:model绑定的对象里面的属性。
也是操作 :model 对象去 处理数值的
